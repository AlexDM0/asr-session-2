    Step 3 of 6

    Connect it to Copilot

    Create .mcp.json in the root of 1-mijn-duinzicht, the portal folder.

    {
  "mcpServers": {
    "duinzicht-products": {
      "type": "http",
      "url": "http://localhost:3333/mcp",
      "tools": ["*"]
    }
  }
}

    Use .mcp.json, not .vscode/mcp.json: VS Code marks that one deprecated and Copilot CLI does not read it.

    1. Trust the folder. In Restricted Mode VS Code loads no MCP server. Not asked? Run Workspaces: Manage Workspace Trust.
    2. Start it. Click Start above the entry in .mcp.json, or run MCP: List Servers and pick duinzicht-products.
    3. Check the tools. In the chat input, open Configure Tools.

    Copilot CLI: copilot mcp list in the portal folder.

    Done when
