# Session 2 repository

Every folder here is a separate project. Work only inside the folder you were started in.

- `1-mijn-duinzicht/` is the customer portal. Its rules are in `1-mijn-duinzicht/.github/copilot-instructions.md`.
- `2-duinzicht-products-mcp/` is a separate service. Reach it only through its MCP server. Never read,
  search, list or open its files from another folder, including through the terminal.

If your working directory is this repository root, work only in `1-mijn-duinzicht/` and run every
command from there. If a task needs a file outside your folder, stop and ask.
